multifile_honeygrid

Программа на с++ ROOT.

Программа реализует адаптивную анизотропную перепикселизацию — продвинутый метод
преобразования данных с гексагональной камеры телескопа IACT
Imaging Atmospheric Cherenkov Telescope) в высокодетальную квадратную сетку
с сохранением физически значимой структуры изображения ливня.

Для каждого пикселя-хита с координатами (x, y) и амплитудой сигнала A выполняется:

Шаг 1: Анализ окрестности
Берётся окно радиусом neighborhood_radius (по умолчанию 7.5 см ≈ 5× размер пикселя).
В окно включаются все соседние хиты с ненулевой амплитудой.
Амплитуды используются как веса при вычислении статистики.

Шаг 2: Вычисление главных компонент (взвешенный PCA)
Рассчитывается ковариационная матрица:
[ σₓₓ   σₓy ]
[ σₓy   σyy ]
где элементы взвешены амплитудами соседних хитов.

Из неё извлекаются:
Угол ориентации θ — направление главной оси ливня в локальной области:
θ = ½·atan2(2·σₓy, σₓₓ - σyy)
Длины полуосей эллипса рассеяния:
σ₁ = √λ₁  (главная ось — вдоль ливня)
σ₂ = √λ₂  (побочная ось — поперёк ливня)
где λ₁, λ₂ — собственные значения ковариационной матрицы.

Вместо изотропного «размазывания» амплитуды Aᵢ по окружности, сигнал распределяется по эллипсу, 
выровненному по локальному направлению ливня:
Формирование эллипса влияния:
Полуоси эллипса масштабируются:
a = spread_factor × σ₁, b = spread_factor × σ₂ (по умолчанию spread_factor = 1.5)
Минимальный размер осей ограничен (min_axis_size = 1.5 см), чтобы избежать вырождения в шумовых областях.

Для каждого бина квадратной сетки (размер бина 0.5 см) вычисляется нормированное эллиптическое расстояние:
dist_aniso = √[ (dx_rot/a)² + (dy_rot/b)² ]
где (dx_rot, dy_rot) — координаты относительно центра хита в системе, повёрнутой на угол θ.

Вес бина определяется функцией weight_type:
"gauss" (по умолчанию): w = exp(-1.5 · dist_aniso²) — плавное гауссово затухание
"linear": w = 1 - dist_aniso — линейное убывание
"quad": w = 1 - dist_aniso² — квадратичное убывание
"const": w = 1 внутри эллипса — прямоугольное окно

Веса нормируются так, чтобы полная амплитуда сохранялась:
Σ wⱼ = 1  →  Aᵢ распределяется как Σ (Aᵢ · wⱼ)
